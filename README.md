# Реадмі

Це Тг-бот створений **"NKB STUDIO"** , для зручності запису озвучки для деяких проектів :eyes:



## Майбутні можливості

>### Для адміна:

**Інфа по бд в самому тг-боту, команда: /info** :black_circle:

>### Для юзера:

**Кнопка донат, команда /donate** :trollface:
**Оновити кнопку статистику(бд)**

>### Для самого бота:

**Обновити бд**
